Six-Sided Die Distribution

1. Original Population

The original population represents the outcomes of rolling a fair six-sided die. It is a discrete uniform distribution because there are six possible values (1 through 6), and each has an equal probability of occurring. Unlike the Standard Normal distribution, the original population is not bell-shaped.

Theoretical mean: 3.5

Theoretical standard deviation: approximately 1.708

2. Monte Carlo Simulation

I used Monte Carlo simulation to examine the sampling distribution of the sample mean for a fair six-sided die at different sample sizes. For each sample size, I repeatedly simulated rolling a die and calculated the average outcome of each sample.

Sample sizes tested: 2, 4, 5, 10, 20, 25, 30, 35, 40, 45, 50, 55, 100

Number of simulations: 10,000 for each sample size

# sample sizes to test
sample_sizes <- c(2, 4, 5, 10, 20, 25, 30, 35, 40, 45, 50, 55, 100)

# number of repeated samples
num_simulations <- 10000

# function to simulate sample means
simulate_means <- function(n) {
  replicate(
    num_simulations,
    mean(sample(1:6, size = n, replace=TRUE))
  )
}

# run the simulation for every sample size
simulation_results <- lapply(sample_sizes, simulate_means)

# name each result by its sample size
names(simulation_results) <- sample_sizes

I used histograms and Normal Q-Q plots to examine how the sampling distribution of the sample mean changes as the sample size increases. Since the original population is discrete uniform rather than Normal, I expect the sampling distributions to become more approximately Normal as the sample size increases.

4. Numerical Evidence

In addition to the histograms and Q-Q plots, I calculated numerical values to check how close the sampling distributions are to normal. I compared the simulated means and standard errors with their theoretical values. I also calculated skewness and excess kurtosis to see how the shape of the sampling distributions changes as the sample size increases.

# function to calculate skewness
skew <- function(x) {
  m3 <- mean((x - mean(x))^3)
  m2 <- mean((x - mean(x))^2)
  m3 / m2^(3/2)
}

# function to calculate excess kurtosis
kurt <- function(x) {
  m4 <- mean((x - mean(x))^4)
  m2 <- mean((x - mean(x))^2)
  m4 / m2^2 - 3
}

5. Approximately Normal?

Selected sample size (n): 10

I consider the sampling distribution approximately normal at n = 10. From the histograms, I notice that the distribution is already fairly symmetric and bell-shaped, and the bars follow the red Normal curve closely. The Q-Q plot also shows that most of the points follow the reference line, although there are still some deviations at the tails.

At smaller sample sizes, especially n = 2 and n = 5, the histograms have more noticeable gaps and spikes, and the Q-Q plots show more steps. By n = 10, these differences become less noticeable, the bars aligned closely with the reference curve, which makes me comfortable considering the sampling distribution approximately normal.

The numerical evidence also supports my decision. At n = 10, the skewness is -0.031, which is close to 0, and the excess kurtosis is -0.181. Although the excess kurtosis is not exactly 0, it is much closer than at n = 2 (-0.657). The simulated standard error is 0.536, which is close to the theoretical standard error of 0.540. This shows that the simulation agrees with the expected variability of the sample means, although matching standard errors alone does not prove normality.

While the sampling distributions at n = 20 and above follow the Normal curve more closely, the goal is to find the smallest sample size where the sampling distribution looks approximately normal, rather than the sample size with the closest fit. Based on the visual and numerical evidence, n = 10 seems reasonable.

6. Limitations and Surprises

One limitation of this experiment is that the decision of when the sampling distribution becomes approximately normal is based partly on visual judgement. Even though I selected n = 10, there is no exact cutoff that determines when a distribution is normal enough. The results are also based on 10,000 simulations, so the histograms and numerical values may change slightly with a different random seed.

One thing I found interesting was that the sampling distribution started looking bell-shaped at relatively small sample sizes, even though the original die population is not normal. I also noticed that skewness was already close to 0 at n = 2, but the histogram and Q-Q plot still showed noticeable differences from a normal distribution. This shows that having skewness close to 0 does not necessarily mean a distribution is normal.

7. Conclusion

The Six-Sided Die experiment showed that the sampling distribution of the sample mean can become approximately normal even when the original population is not normally distributed. Based on the visual and numerical evidence, I selected n = 10 as the smallest sample size where I felt comfortable calling the sampling distribution approximately normal.

As the sample size increased, the histograms became smoother and more bell-shaped, and the Q-Q plots followed the reference line more closely. The standard error also decreased, meaning the sample means became more concentrated around the theoretical mean of 3.5. This supports the Central Limit Theorem, which states that the sampling distribution of the sample mean approaches a Normal distribution as the sample size increases, assuming the necessary conditions are met.

Unlike the Standard Normal experiment, where the sampling distribution was already normal at n = 2, the Six-Sided Die experiment showed a more noticeable change in shape as the sample size increased. This suggests that n = 30 is not always necessary, and the sample size needed for approximate normality depends on the original population.
